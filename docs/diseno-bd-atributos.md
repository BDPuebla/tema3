# Atributos

Hemos podido observar que los atributos son las propiedades o características de una entidad o relación en un modelo de datos. Cada atributo tiene un nombre y un dominio, que define el conjunto de valores posibles que puede tomar. Los atributos pueden ser simples o compuestos, y pueden tener restricciones de integridad asociadas.

En el nivel lógico del diseño de bases de datos, se definen los atributos y sus propiedades en el esquema relacional. Cada tabla tiene un conjunto de atributos que definen su estructura y los valores que pueden almacenar.

Hemos visto los diferentes tipos de datos que se pueden utilizar para los atributos, como números, cadenas de texto, fechas y booleanos. Además, hemos aprendido a definir restricciones de integridad para garantizar la validez y consistencia de los datos almacenados en la base de datos.

Es importante recordar que un atributo debe tener un nombre único dentro de la tabla, un tipo de datos específico y, opcionalmente, restricciones adicionales que se aplican al atributo. Esto asegura que los datos almacenados en la base de datos sean válidos y consistentes con las reglas de negocio.
