# Tema 3: El Lenguaje SQL: Definición de datos.

El presente tema se centra en el lenguaje SQL (Structured Query Language) y su aplicación en la definición de datos dentro de bases de datos relacionales. A lo largo del tema, se explorarán los conceptos fundamentales para crear y gestionar una base de datos, incluyendo la creación de tablas, la definición de relaciones entre ellas y la implementación de restricciones de integridad.

## Objetivos del tema

Los objetivos principales de este tema son:

* Comprender los conceptos básicos del lenguaje SQL y su importancia en la gestión de bases de datos.
* Aprender a crear y modificar tablas utilizando sentencias SQL.
* Definir relaciones entre tablas y aplicar restricciones de integridad para garantizar la consistencia de los datos.
* Familiarizarse con las mejores prácticas en el diseño y modelado de bases de datos relacionales.

## Contenido

El contenido del tema se organiza en las siguientes secciones:

1. Introducción
2. Diseño de bases de datos relacionales
3. Definición de datos con SQL
4. Creación de tablas y relaciones
5. Restricciones de integridad
6. Índices y Vistas
