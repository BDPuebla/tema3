# Creación de tablas

En esta sección, veremos como crear, modificar y eliminar tablas en una base de datos. Para ello, utilizaremos el lenguaje SQL y sus sentencias específicas para la gestión de tablas.

En este aspecto partimos desde una base de datos ya normalizada y con las relaciones entre tablas ya definidas, por lo que nos centraremos en la creación de las tablas y sus atributos.

Es importante recordar que la creación de tablas es un paso fundamental en el diseño de una base de datos, ya que define la estructura de los datos que se almacenarán y cómo se relacionarán entre sí. Además, una buena definición de las tablas y sus atributos puede mejorar el rendimiento de las consultas y facilitar el mantenimiento de la base de datos a largo plazo.

También hay que incidir en que la creación de tablas requiere conocer no solo las tablas ya normalizadas; sino también el dominio de los atributos que se van a definir, ya que cada atributo debe tener un tipo de dato específico y restricciones adecuadas para garantizar la integridad de los datos.

En este aspecto, vamos a ver cómo crear tablas en SQL, cómo definir sus atributos y restricciones, y cómo modificar o eliminar tablas según sea necesario. Además, se presentarán buenas prácticas para la creación de tablas y se discutirán algunos errores comunes que se deben evitar al trabajar con ellas.
